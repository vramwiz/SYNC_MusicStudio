# 演奏スタジオ / SYNC_MusicStudio

AviUtl2で音楽素材とPSDキャラを使い、演奏・歌唱・感情・リズム同期を編集するプラグイン。

**SYNC / 演奏スタジオ**の設定ボタンから、FL Studioを参考にした1ページの編集画面を開く。
音声・歌唱、共有PSDと母音、PSD別の表情・アニメーション・楽器姿勢、拍単位の演奏を編集できる。

- 「トラック＋」で音声・歌唱PSD・楽器トラック（歌唱も可能）を追加し、右のスロットを選ぶ。
  左の見出し・一覧・＋はスロットの受入属性へ切り替わる。単一属性なら直接追加、複数なら対応属性のメニューを開く。
  歌唱＋表情などの混在枠でも、割当PSDの共有パターンを同じ一覧から選べる。
- パターンをダブルクリックして共通の名前・色と、属性専用の設定を編集する。
  音声はWAV/MP3・実波形・音量、歌唱はMIDI/KAR・使用トラック・音符/歌詞/かな母音。
- 歌唱PSDスロットの＋からPSDを共有登録し、実際の部位を一覧から母音へ割り当てる。
  通常・あ/い/う/え/お/ん・小さいあ/い/う/え/おの12枠。小さい母音の未割当時は通常サイズを使う。
  先にレイヤーの行を選び、右クリックまたは「母音へ割当…」から対象母音を選ぶと即割当・プレビューする。
  ↑↓で行を選び、Enter・Shift+F10・メニューキーでも割当メニューを開ける。メニューのチェックと「選択: … / 割当: …」で登録済み母音を確認できる。
  親グループは太字、子は浅い字下げで実レイヤーの短い名前を表示。完全な階層・同名の区別はツールチップで確認する。
  行を選ぶだけでその表情をプレビューする。この選択は母音割当や保存設定を変更しない。
  歌唱PSD一覧の左列は約2文字幅。「通常」「あ～ん」「小あ～小お」、複数割当は「通+」「あ+」等で表示し、全文はツールチップで確認する。割当の有無によらず名前の開始位置を揃える。
  プレビュー上のホイールでカーソルを基準に拡縮、左ドラッグで移動。「全体表示」またはダブルクリックで戻す。
  行選択や母音割当中も表示倍率・位置を維持し、合成完了まで直前の画像を表示する。
  「確認: …」は表示確認用。「確認母音を解除」はその母音だけ、メニュー末尾は選択レイヤーの割当をまとめて解除する。
  登録済みPSDは右の歌唱PSDスロットを選択し、左のPSD一覧をダブルクリックして開く。右のスロット自体の設定とは別の入口。
  左の共有PSDをスロットへドラッグするとトラックへ割り当てる。
- 表情・アニメーション・楽器姿勢は割当PSD専用の一覧。表情と姿勢は部位の表示設定、
  アニメーションはリズム変形・移動・拡大・回転と無音画像プレビュー。
- 「スロット＋」で種類別の枠を追加する。楽器側PSDにも歌唱/口パク枠を追加できる。
  共通設定枠で名前・色・受入属性、右クリックで順番変更・削除を操作する。
- 配置はドラッグで移動し、ダブルクリックまたは右クリックで開始・長さを編集する。
  音声・歌唱MIDIは秒、演奏は拍で保持する。ホイールズームに応じて演奏の拍スナップも変わる。
  演奏ポップアップのピアノロールで音符を追加・移動・削除する。Ctrl＋ホイールで時間ズーム、Shift＋ホイールで横移動。
  「テンポ・拍子」でテンポ変化と曲全体の固定拍子を編集する。BPMを変えても演奏の拍位置は変わらない。
- トラック見出しのクリックで展開/折りたたみを切り替える。折りたたみ中も配置を表示し、複数スロットは別の段と番号で区別する。
  音声クリップ内には実波形を表示する。同じ音源の解析結果と表示タイルを共有し、再描画/ズームでは音源を再解析しない。
  歌唱クリップ内には使用MIDIトラックのピアノロールを表示する。PSD見出しの右端には固定の合成画像サムネイルを表示する。
  歌唱の音域は休符で区切られたフレーズごとに高さへ合わせる。フレーズ内の音程差を維持し、スクロール・ズーム・配置の途中切断でも表示音域は変えない。
  同じMIDI/PSDはプレビューとも解析結果を共有し、更新日時/サイズが変わると更新する。
- 上部の再生/一時停止/停止で編集プレビューを確認する。シークバーと時間目盛のクリックで位置を変更。
  AviUtl2では自身のPSD合成前の入力背景を静止画として表示し、背景の比率と実出力の等幅・中央・下揃えを保って重ねる。
  背景はホストの描画時に更新。再描画なしの再オープンでも最新取得フレームを保持し、カーソルとの差は背景ツールチップに表示する。編集側のシークでAviUtl2のカーソルは移動しない。対象が一度も描画されていない場合は黒背景と「背景未取得」を表示。取得不能/独立EXEでは従来の黒背景。
  通常モードでは音声配置の開始・長さ・音量を反映する。PSDは部位・母音・表情・姿勢とアニメーションを表示する。
  歌唱MIDIは配置位置に応じた歌詞/音高を表示する。歌声は生成しない。
  母音が切り替わる間も直前の完成画像を表示し、最新世代の合成完了時にバッファ付き描画面へ差し替える。
- JSON保存/読込、または「適用して閉じる」で保存する。キャンセルはAviUtl2に反映しない。

JSONは外部ファイル参照のみ。元の音声/MIDI/PSDは変更しない。
共有データはKnown FolderのDocuments配下`SYNC_MusicStudio/Libraries/PSDAssets/<固定ID>/`に管理コピーと設定を保存する。
同内容は同ID、同名異内容は別ID。元のCharacters/PNG・PSDは変更しない。欠損は同内容のPSDから同じIDへ復旧できる。
共有設定は確認ボタンで独立保存され、作品のキャンセルでは戻らない。
歌声生成、音符からの手足動作生成、途中の拍子変更、ドラムステップは未対応。
試聴は最大32音声配置、プレビューのPSDは先頭4トラック。先頭4件と可視配置/見出しのMIDI/PSDを順次読み込む。
PSDはv1/RGB8/raw・RLE、通常合成と画像マスク。特殊合成・クリッピング・グループマスク等は未対応理由を表示する。
16M画素・512MiBの読込予算、共有表示画像は長辺512px以内。

AviUtl2映像には、設定済みPSDの先頭4トラックを透明背景で等幅・中央・下揃えに表示する。
歌唱MIDIの配置と使用トラックからオブジェクト内時刻に合う母音を選び、表情・姿勢・animationも既存の評価を使う。
背景映像へ重ね、音声は出力しない。キャラ位置/サイズの手動編集は次段階。
映像用の素材は初回/JSON変更/設定画面終了後に読み込み、その後は固定snapshotを使う。
共有素材を別の場所で編集した場合は「設定」を開いて閉じると映像へ再反映する。
所有APIはSDK履歴の2026/7/25追加（本体2.1.2）。このPCの2.1.3a/2.1.6aは追加後の版であり、最新版への更新は前提にしない。

表情/PSD配置の操作:

- 表情スロットを選ぶと左一覧と配置クリップに合成画像を表示。配置を選び、左右端で長さ、中央で開始位置を変更する。
- 歌唱PSDスロットを選ぶと上のプレビューに選択枠が出る。内側で移動、4隅で縦横比を保つ拡縮、右クリックで左右/上下反転。
- 灰色余白へのはみ出しも編集可能。四隅トンボが映像の出力範囲。配置は作品JSONだけへ保存する。
- Escapeは進行中のドラッグ取消、Ctrl+Zは元へ戻す、Ctrl+Yはやり直す。JSON保存/読込で配置と反転を保持する。

演奏stepの操作:

1. 歌唱PSDトラックのPSDスロットへ共有PSDを割り当て、スロット＋で「演奏」を追加して選ぶ。
2. 左＋で演奏パターンを作り、ダブルクリック。パターン長を拍で指定し、マスを選び、下のレイヤーを表示チェックする。
3. ＋/−またはCtrl+ホイールで横ズーム。マスの刻みだけが変わり、既存stepはそのまま。選択step長も拍で変更できる。
4. OK後、左のパターンを演奏スロットへD&Dする。上部BPM/拍子ボタンで曲テンポを変更する。
5. 保存/取消/UndoRedoは作品JSONだけに作用する。音声/歌唱MIDIは秒、演奏は拍。パターン長と配置長は独立、loopはしない。

小節・テンポの操作:

1. タイムラインは小節・拍。選択クリップの中央で移動、左右端で長さを変更し、表示グリッドへ吸着する。表示ズームだけでは既存データを変えない。
2. 小節ルーラーを右クリックして手動tempo点を追加/変更/削除する。0拍の点は削除できない。上部BPM/拍子は曲の手動設定。
3. 音声/歌唱PSDトラックのスロット＋→「テンポ」。そのスロットを選び、左＋からパターンを追加してダブルクリックする。
4. 「MIDIから読込…」でSMF0/1・PPQの明示tempoを取り込み、OK後にD&Dで配置する。MIDIの途中拍子変更は未適用と表示する。
5. 配置区間だけ曲全体へ作用する。新しい開始拍のclipを優先、同時なら後ろのtrack/slot/clip順。終了・削除後は下のclip/手動tempoへ戻る。
